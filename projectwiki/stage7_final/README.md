# 7. 최종 그래프 (`stage7_final`)

5단계 그래프 + 6단계 교정 제안 + 사용자의 직접 편집을 합쳐 최종 그래프를 만듭니다.

- **입력**: `Graph`, `Correction`, 피드백 이벤트
- **출력**: `Graph` (`<출력폴더>/final_graph.json`)

| 파일 | 내용 |
|---|---|
| `finalize.py` | ① 교정 제안 적용 (import·링크는 숨기지 않음) → ② 직접 편집을 순서대로 다시 적용 (나중 이벤트 우선) → ③ 점수 기준 정리, 그룹 구성원 다시 계산 |

**지키는 규칙**

- 사용자가 추가하거나 승인한 연결은, 다시 생성할 때 AI가 제안하지 않아도 사용자 연결로 남습니다.
- 거절한 연결은 다시 제안되어도 거절 상태로 남습니다.
- 피드백 로그 자체는 `feedback.py`(패키지 최상위)에서 읽고 합칩니다.
