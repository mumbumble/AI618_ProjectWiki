# 연구실 간식 예산

이 문서는 연구실 공용 간식 구매 예산을 관리하기 위한 메모입니다. 구매 담당자는 매월 영수증을 정리해 행정 담당자에게 넘깁니다.

## 월 예산

- 월 총 예산: 150,000원
- 대상 품목: 원두(커피), 쌀과자, 요거트
- 이월: 불가 (매월 말 정산 후 마감)

## 품목별 배분

| 품목 | 월 배정액 | 비고 |
|---|---|---|
| 원두 (커피) | 80,000원 | 500g 또는 1kg 단위로 구매 |
| 쌀과자 | 35,000원 | 대용량 묶음 우선 |
| 요거트 | 35,000원 | 플레인과 과일 혼합을 번갈아 구매 |
| 합계 | 150,000원 | |

## 11월 구매 기록

| 날짜 | 품목 | 수량 | 금액 |
|---|---|---|---|
| 11/03 | 원두 | 1kg 리필 | 38,000원 |
| 11/03 | 쌀과자 | 대용량 2봉 | 12,400원 |
| 11/10 | 요거트 (플레인) | 6개입 2묶음 | 15,800원 |
| 11/17 | 원두 | 500g | 21,000원 |
| 11/18 | 쌀과자 | 1봉 | 6,200원 |
| 11/19 | 요거트 (딸기) | 6개입 1묶음 | 8,900원 |
| 합계 | | | 102,300원 |

- 11월 잔여 예산: 47,700원 (150,000원 − 102,300원)

## 품목별 사용 현황 (11월)

- 원두: 59,000원 사용 (배정 대비 73.8%)
- 쌀과자: 18,600원 사용 (배정 대비 53.1%)
- 요거트: 24,700원 사용 (배정 대비 70.6%)

원두 배정액이 가장 크지만 사용률은 쌀과자가 가장 낮습니다. 12월에는 쌀과자 구매 횟수를 줄이고 대용량 묶음으로 바꾸는 방안을 검토합니다.

## 구매 절차

1. 품목이 떨어지기 전 주 금요일까지 간식 요청 게시판에 필요한 품목을 남깁니다.
2. 구매 담당자는 같은 주 안에 구매하고 영수증을 사진으로 찍습니다.
3. 영수증 사진은 공용 드라이브의 간식 영수증 폴더에 보관합니다.
4. 월말에 위 구매 기록 표를 갱신하고 행정 담당자에게 전달합니다.

## 주의 사항

- 1회 구매 금액이 50,000원을 넘으면 사전에 행정 담당자의 확인을 받습니다.
- 개인 취향이 강한 음료나 간식은 공용 예산에서 구매하지 않습니다.
- 요거트는 구매 시 유통기한을 확인하고, 기한이 3일 이내로 남은 제품은 피합니다.
- 원두는 개봉 후 밀폐 용기에 보관하고, 개봉일을 용기에 적어 둡니다.

## 메모

- 12월에는 연말 모임 간식이 추가로 필요할 수 있어 예산 초과 여부를 미리 행정 담당자와 상의합니다.
- 예산 항목 변경이 필요하면 월말 정산 전에 요청합니다.
- 구매 기록 표의 금액은 영수증 기준으로 적고, 할인 금액은 실제 결제 금액에서 차감한 값을 씁니다.
