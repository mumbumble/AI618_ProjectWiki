### 박도현 담당 피처 엔지니어링 세부 내용
- 시간 주기 인코딩: hour를 sin, cos 값으로 변환해 23시와 0시가 가깝게 인식되도록 함
- 주말 여부 변수 생성
- 강수 여부 플래그: 시간당 강수량이 0보다 크면 1
- 온도와 습도를 곱한 상호작용 변수 생성
- 계절 원-핫 인코딩 (Winter, Spring, Summer, Autumn)
- 위 기능을 함수 형태로 작성해 모델링 노트북에서 바로 불러 쓰고, 입력행렬(X)과 타깃(y)을 반환하도록 함

## 3. 결정 사항

1. 모델: Random Forest Regressor를 주 모델로 사용 (n_estimators=200, max_depth=8, random_state=42). Linear Regression을 기준 모델로 둔다.
2. 결측 처리: 결측 행을 삭제하지 않고, temp_c와 humidity_pct는 같은 계절의 중앙값으로 채운다.
3. 데이터 분할: 정제 데이터 기준 80/20 train/test 분할, random_state=42.
4. 그림 파일은 report/figures 폴더에 저장한다.
5. 보고서 최종본은 report 폴더에 작성한다 (마크다운 또는 PDF 허용).
6. 정제 데이터 push 마감은 11-10 (화)이다.

## 4. 정제 규칙 (초안 합의)

- 쉼표를 제거한 뒤 rented_bikes를 정수로 변환한다 (예: "1,204" → 1204).
- rented_bikes가 "n/a"로 적힌 2행은 처리 방식을 이서연이 확인해서 다음 주 회의에 보고한다.
- 결측 temp_c, humidity_pct는 계절별 중앙값으로 채운다.
- holiday 표기를 통일한다: "no holiday" → No Holiday, "Holliday" → Holiday.
- hour가 0-23 범위를 벗어나는 행(hour=24)은 제거한다.
- datetime 문자열을 파싱하고 중복 행을 제거한다.
- 최종 출력은 20-35행, 원본과 같은 10개 열을 유지한다.
- 정제 스크립트는 `python src/clean_data.py` 한 줄로 실행되어야 한다.
