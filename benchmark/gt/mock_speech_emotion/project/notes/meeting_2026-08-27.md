## 2. Ablation 계획 및 결과 (A1–A4)

모든 ablation 은 setting all, seed 1234 고정으로 돌린다. 논문 v2 Table 2 와 같은 값이다.

| 항목 | 제거한 요소 | UA (all) | 변화 |
|---|---|---|---|
| Full ProsodySER | - | 72.4 | - |
| A1 | prosody bias 제거 (lambda 0 고정, content-only pooling) | 69.7 | -2.7 |
| A2 | delta feature 제거 (prosody_dim 3) | 71.0 | -1.4 |
| A3 | language-adversarial loss 제거 (lang_loss_weight 0) | 70.8 | -1.6 |
| A4 | attention pooling 을 mean pooling 으로 교체 | 68.2 | -4.2 |

분석:
- 가장 큰 기여는 pooling attention 자체다 (A4, -4.2). attention 을 쓰는 것만으로도 mean pooling 보다 크게 올라간다.
- 그 다음이 prosody bias 다 (A1, -2.7). 같은 attention 구조라도 F0/energy 기반 bias 가 없으면 성능이 떨어진다. 이 결과가 논문의 핵심 주장을 뒷받침한다.
- language-adversarial branch 는 A3 에서 -1.6 이다. 전체 수치보다는 영어 쪽 개선에 주로 기여한다는 경향이 보여서, 언어별 분석을 논문에 넣기로 했다.
- delta feature (A2, -1.4) 는 효과가 작지만 일관되게 도움이 된다. 6차원 prosody 입력을 유지한다.
- 실험 순서: A1–A4 를 먼저 돌리고, 언어별 UA 는 결과가 나오는 대로 표에 추가한다.

## 3. 논문 일정

- 논문 파일: paper/prosody_ser_draft_v2.pdf
- v2 마감: 2026-09-30 (김서연 주도)
- 워크숍 제출: 2026-10-15 (SpeechAffect Workshop 2026)
- 제목은 v1 과 동일하게 유지: "Listening to How It Is Said: Prosody-Aware Attention for Bilingual Korean-English Speech Emotion Recognition"
- 방법 섹션 체크리스트:
  - Figure 1 박스 이름 (Waveform, Log-Mel, Conv Stem, Transformer Encoder, Prosody Extractor, Prosody Encoder, Prosody-Aware Pooling, Emotion Classifier, Gradient Reversal, Language Classifier) 을 그림과 캡션에서 동일하게 쓴다.
  - Prosody feature 는 6차원 [logf0_z, energy_db, voiced, d_logf0, d_energy, d_voiced] 로 쓴다.
  - Pooling 은 4 heads, lambda 초기값 0.5, 출력은 256 으로 투영한다.
  - 손실은 L = L_ce + 0.2 * L_lang, label smoothing 0.1, GRL 강도는 처음 5 epoch 동안 0 에서 1 로 증가시킨다.
  - 모델 크기 11.3M, 학습 약 2.1 h (A100 40GB, 30 epoch).
- 한계 (논문에 명시): 연기 기반 acted speech 만 사용, 2개 언어, whispery 음성에서 F0 추출 실패, SNR 실험은 babble noise 만 사용.
