# 향후 연구 아이디어 (ProsodySER)

현재 버전의 ProsodySER(PAP + 언어 적대 분기)을 기준으로 다음 단계에서 시도할 아이디어를 정리한다. 아래 항목은 아직 실험하지 않은 제안이며, 현재 논문 결과에는 포함되지 않는다.

## 1. Prosody Encoder 다중 스케일화

- 현재: Prosody Encoder는 kernel 5 conv 2층(hidden 128)으로 프레임 단위 p_t를 만든다. 수용 영역이 짧아서 음절 수준의 F0/energy 변화까지만 본다.
- 제안: 음절 수준 브랜치(짧은 kernel)와 구(phrase) 수준 브랜치(dilated conv 또는 pooling 후 확장)를 나란히 두고 p_t를 합친다.
- 기대: 문장 끝 억양처럼 긴 구간의 F0 변화가 prosody bias g_t에 반영되어, 비슷한 F0 패턴을 가진 감정 간 구분이 나아질 수 있다.
- 확인 방법: 같은 split과 seed로 비교하고, 결과는 95% bootstrap CI와 함께 보고한다.

## 2. λ 구조 확장

- 현재: λ는 학습 가능한 스칼라 하나이고 초기값은 0.5다. 모든 pooling head와 모든 층이 같은 값을 쓴다.
- 제안 (a): head마다 λ_h를 따로 둔다.
- 제안 (b): 층마다 λ를 두거나, 입력에 따라 λ를 계산하는 게이트를 둔다.
- 주의: λ가 음수로 가면 해석이 어려우므로 clamp나 sigmoid 매개변수화를 함께 검토한다.
- 확인 방법: A1(prosody bias 제거) 대비 이득이 실제로 늘어나는지 본다.

## 3. 언어 정보 제거 방식 교체

- 현재: Gradient Reversal Layer를 거쳐 Language Classifier를 학습하고, L_lang 가중치는 0.2다. 반전 강도는 처음 5 epoch 동안 0에서 1까지 올린다.
- 제안: GRL 대신 언어 간 contrastive alignment를 사용한다. 같은 감정이면 언어가 달라도 임베딩을 가깝게 두는 방식이다.
- 이유: 적대 학습은 학습이 불안정할 수 있고, A3(언어 분기 제거)에서 보듯 영어 쪽 성능에 영향이 크다.
- 확인 방법: lang_loss_weight 조정 실험과 같은 조건에서 ko/en을 따로 본다.

## 4. 화자 정규화 F0 개선

- 현재: log-F0는 화자별 z-score로 정규화한다. 화자당 발화 수가 적을 때 통계가 불안정할 수 있다.
- 제안: 화자 통계를 더 안정적으로 추정하는 방법(예: 유성음 구간만 사용, 발화 수가 적으면 언어별 평균으로 보정)을 검토한다.
- 한계: F0 추출이 속삭임 음성에서 실패하므로, voicing 정보가 없는 구간의 fallback 처리도 같이 다룬다.

## 5. 코드스위칭 테스트 세트

- 현재 테스트는 한 발화가 한 언어로만 된 데이터에서 이루어진다.
- 제안: 한국어와 영어가 한 발화 안에서 섞이는 코드스위칭 테스트 세트를 만든다. 언어 전환 지점 근처의 감정 인식 성능을 따로 측정한다.
- 필요 작업: 녹음 대본 설계와 라벨링 일정을 정민지 연구원과 먼저 협의한다.

## 6. 제3 언어(일본어) 추가

- 현재 언어 분류기는 ko/en 2-way다. 일본어를 추가하면 3-way 분류가 되고, 언어 분기의 역할이 더 분명해진다.
- 고려할 점: 화자 수와 감정 클래스 균형을 맞춰야 하고, 언어별 성능 차이를 따로 보고해야 한다.
- 제한: 현재 corpus는 acted speech만 포함하므로, 자연 발화 데이터에서 같은 효과가 나오는지도 확인이 필요하다.

## 7. 잡음 조건 확장

- 현재 SNR 실험은 babble noise만 사용하고 SNR은 20, 10, 5, 0 dB다.
- 제안: 음악, 거리 소음 등 다른 잡음 종류를 추가하고, 잡음 종류별로 gap이 어떻게 변하는지 본다.

## 우선순위 메모

1. 다중 스케일 Prosody Encoder (구현 부담이 적고 효과를 바로 확인할 수 있음)
2. λ 구조 확장 (코드 변경이 작음)
3. 코드스위칭 테스트 세트 (데이터 준비가 필요해서 일정을 일찍 잡아야 함)
4. GRL 교체, 제3 언어 추가, 잡음 확장 (후속 연구 범위)
