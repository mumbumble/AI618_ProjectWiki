# 학회 출장 계획: Seoul Open Geo Summit (부산)

## 1. 일정 개요

- **학회명**: Seoul Open Geo Summit
- **장소**: 부산 해운대 일대
- **기간**: 2026-12-03(목) ~ 2026-12-05(토)
- **목적**: 공개 지리 데이터 도구 세션 참관, 발표 세션 메모, 참석자 네트워킹

| 날짜 | 요일 | 주요 일정 |
|------|------|-----------|
| 12-03 | 목 | 서울역 출발 → 부산 도착, 숙소 짐 보관, 등록 및 개회 세션 |
| 12-04 | 금 | 종일 발표 세션, 포스터 부스 방문, 저녁 네트워킹 |
| 12-05 | 토 | 오전 클로징 세션, 귀경 |

세부 시간표는 학회 홈페이지에서 최종 확인할 것. 세션 변경이 잦으므로 출발 전날 한 번 더 본다.

## 2. 교통

### 가는 길
- **KTX**: 서울역 07:40 출발, 부산역 도착 예정 약 10:20 (소요 약 2시간 40분)
- 부산역에서 해운대 숙소까지 지하철 2호선 또는 택시 이용
- 열차표는 출발 2주 전에 예매 완료. 좌석 번호와 승차권 번호를 휴대폰에 저장

### 오는 길
- 12-05(토) 오후 귀경 열차 예약. 시간은 클로징 세션 종료 시각을 보고 결정
- 귀경 열차 예매는 11-28까지 확정하지 않으면 좌석이 부족할 수 있음

## 3. 숙소

- **위치**: 해운대 해수욕장 도보 15분 이내 호텔
- **일정**: 12-03 체크인 ~ 12-05 체크아웃
- **체크인 시간**: 보통 15:00. 이른 도착 시 짐 보관 요청
- **예약 확인 사항**: 조식 포함 여부, 학회 근처 셔틀 유무, 취소 규정

학회장과 숙소 사이 이동이 오래 걸리면 택시 대신 지하철 이용을 고려한다. 비 오는 날은 택시 호출 앱이 더 빠르다.

## 4. 예산 (총 480,000원)

| 항목 | 금액 (원) | 비고 |
|------|-----------|------|
| KTX 왕복 | 130,000 | 서울역 ↔ 부산역 |
| 숙소 (2박) | 200,000 | 해운대 일대 |
| 학회 등록비 | 80,000 | 얼리버드 적용 여부 확인 |
| 식비 | 40,000 | 3일분, 점심 위주 |
| 현지 교통 | 20,000 | 지하철, 택시 |
| 예비비 | 10,000 | 영수증 보관 |
| **합계** | **480,000** | |

지출 내역은 날짜별로 영수증을 모아 두었다가 출장 보고서 작성 시 정리한다.

- [ ] 보조배터리
- [ ] 우산 (12월 부산 강수 가능성 있음)

- [ ] 세면도구, 상비약
- [ ] 발표 자료 USB 백업 및 클라우드 사본

## 6. 현장 메모

- 등록 부스는 개회 전 30분부터 운영될 가능성이 높으므로 일찍 도착하는 편이 좋다.
- 포스터 부스 방문 시 명함과 연락처를 같이 교환하고, 질문 내용은 메모 앱에 날짜와 함께 기록.
- 저녁 네트워킹은 참석 여부를 미리 등록 페이지에서 확인.
- 해운대 시장 근처 식당은 저녁에 붐비므로 예약 가능한 곳을 미리 찾아 둘 것.

## 7. 출장 후 할 일

- 영수증 정리 및 출장비 정산 신청 (12-12까지)
- 세션 메모 정리본 작성, 팀 공유 폴더에 업로드
- 새로 받은 명함 연락처 정리 및 감사 메일 발송
