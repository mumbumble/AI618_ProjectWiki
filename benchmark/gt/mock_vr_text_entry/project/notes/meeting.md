## 2. 현재 확정 결과 요약

**가설 판정**

- H1 (스와이프가 더 빠르다): 지지됨
- H2 (스와이프는 오류가 더 많다, 속도-정확도 상충): 지지됨

**과제 수행 시간 (과제당 평균 초, 16명 기준)**

- ray: 41.8초 (SD 9.6)
- swipe: 33.2초 (SD 8.1)
- 감소율 20.6%
- Wilcoxon signed-rank (양측): W = 7, p = .002, r = 0.79

**오류 (과제당 평균, 16명 기준)**

- ray: 1.9 (SD 1.1)
- swipe: 3.4 (SD 1.6)
- 증가율 79%
- Wilcoxon signed-rank (양측): W = 10, p = .004, r = 0.74

**속도 (WPM, T1+T2 기준)**

- ray 15.1 / swipe 19.0

**주의:** 중간 분석(n = 12) 수치(ray 42.5초, swipe 35.0초, p = .01)는 최종 보고에서 사용하지 않는다. 파일럿(n = 4, v0.3.2) 수치도 본문에는 넣지 않고 방법 절의 참고용으로만 쓴다.

## 3. 교수 지적 및 지시 사항

1. **속도-정확도 상충을 더 전면에 배치할 것.** 현재 findings.md에서는 시간 결과가 앞에 나오고 오류 결과는 뒤에 밀려 있다. 두 결과를 같은 무게로 한 문단에 묶어서 "빠르지만 더 많이 틀린다"는 구조가 드러나야 한다.
2. **팔 피로도(Q4)를 더 눈에 띄게 보고할 것.**
   - Q4 평균: ray 3.3 / swipe 4.6 (높을수록 피로 큼), Wilcoxon p = .011
   - 면담에서도 피로 언급이 많았는지 함께 정리한다.
3. **제안서의 계획된 분석과 실제 분석이 일치하는지 확인할 것.** `proposal/study_proposal.pdf`에 Wilcoxon signed-rank가 명시되어 있는지 확인하고, 결과 절의 검정 방법 설명과 맞춰 본다.
4. **과제별(T1–T4) breakdown 추가.** 아래 표를 결과 절에 넣는다.

## 5. 설문 결과 보충 (Q1–Q8)

- Q2 지각된 속도: ray 4.3 / swipe 5.6 (p = .003)
- Q3 지각된 정확도: ray 5.4 / swipe 4.5 (p = .021), ray가 더 정확하다고 인식
- Q4 팔 피로도: ray 3.3 / swipe 4.6 (p = .011)
- Q7 즐거움: ray 4.4 / swipe 5.7 (p = .004)
- Q1, Q5, Q6, Q8은 유의하지 않음 (Q1 p = .09, Q8 p = .12)
- 메인 그림(Q1–Q8 평균, 95% CI)은 findings.md에 이미 포함되어 있음. 축 이름과 제목은 그대로 유지.

## 6. 박서연 메모

- 시간과 오류 두 검정 사이에 보정을 적용하지 않았다. 논문 방법 절에 이 점을 명시한다.
- Han & Oyelaran (2023)과 비교할 때 ray의 WPM(15.1)이 선행 연구(17.2)보다 낮다. 측정 조건 차이를 논의에 적는다.
- 면담 결과(속도, 정확도, 피로, 즐거움, 재사용 의향, 선호 방식과 이유)는 항목별로 정리해 두고 논의 절에 연결한다.
- IRB 승인 번호는 HCIL-IRB-2026-031이며, 학회 제출 시 윤리 승인 문장에 넣는다.
