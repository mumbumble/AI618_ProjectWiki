RepoSum: Summarizing Functions by Retrieving Their Siblings in the Same Repository

Dohyeon Lee, Yujin Choi, Haneul Jung, Jiwoo Han, Seoyeon Park

Paper (draft v2) Code (reposum 0.3.1) BibTeX

Abstract

Short natural-language summaries of source functions are most useful when they reflect the conventions of the project they come from. Existing retrieval-augmented summarizers either search a global multi-project corpus, where neighbors often use unrelated naming conventions, or concatenate same-file neighbors without learning how to use them. We present RepoSum, which retrieves the k most similar functions ("siblings") from the same repository, encodes each sibling as its code plus its summary, and fuses them into a Transformer decoder through a learned gate. The retriever is trained jointly with an InfoNCE objective whose positives share a call-graph neighbor with the query, and the query itself and any later-commit functions are excluded from the index. On 1,240 Java repositories, RepoSum reaches 26.1 BLEU-4 in the intra-repository setting, 2.4 points above the strongest baseline, and 22.4 BLEU-4 on unseen repositories.

Overview

Method

  • SiblingRetriever. Builds a dense index over the functions of one repository and scores candidates by cosine similarity between the query and candidate embeddings. The query itself and any function from a later commit are removed from the index. The top k = 4 siblings are kept.
  • Sibling weights. The k siblings are weighted by alpha_i = softmax(cos(e_q, e_i) / 0.07).
  • GatedFusion. The context vector c = sum_i alpha_i h_i is combined with the query state as h = h_q + g * c, where g = sigmoid(W [h_q; c]). Each sibling state h_i encodes the sibling code together with its summary.
  • RepoSumModel. A Transformer encoder-decoder with 6 encoder and 6 decoder layers, hidden size 512, 8 heads, and a 32,000-token BPE vocabulary. The fused sibling output is added after the encoder.

Loss. L = L_ce + 0.3 * L_ret. L_ce is the token-level cross-entropy of the summary. L_ret is an InfoNCE loss with temperature 0.07 on the retrieval encoder. Positives are functions that share a call-graph neighbor with the query, and negatives are other in-batch functions from the same repository.

Training. AdamW with learning rate 3e-4, weight decay 0.01, and 1,000 warmup steps. Batch size 32, 20 epochs, dropout 0.1, maximum source length 400 tokens, maximum summary length 48 tokens, seed 13. Beam search with beam size 5 at test time.

Code

The implementation is released as reposum 0.3.1 (Python 3.10, PyTorch 2.2). Training is run with python src/train.py --config configs/intra_repo_java.yaml, and evaluation with python src/evaluate.py --config configs/intra_repo_java.yaml --ckpt checkpoints/best.pt.
