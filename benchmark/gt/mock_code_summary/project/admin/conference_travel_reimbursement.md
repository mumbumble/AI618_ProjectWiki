# 학회 출장 경비 정산 메모

## 출장 개요
- 출장지: 포르투갈 리스본
- 목적: 국제 학회 참석
- 일정: 인천 출발, 리스본 도착 후 4박, 인천 귀국 (왕복 항공 이용)
- 신청 금액: 1,420,000원
- 정산 마감: 2026-10-30

## 경비 내역

| 항목 | 금액(원) | 증빙 |
|---|---|---|
| 항공료 (인천-리스본 왕복) | 880,000 | 전자 항공권, 결제 영수증 |
| 숙박 (4박) | 300,000 | 호텔 인보이스 |
| 현지 교통 | 60,000 | 교통카드 충전 내역, 공항 셔틀 영수증 |
| 식비 | 80,000 | 카드 매출전표 |
| 기타 (여행자 보험, 현지 통신비) | 100,000 | 영수증 |
| **합계** | **1,420,000** | |

## 정산 절차
1. 카드 매출전표와 전자 항공권을 스캔하여 PDF 한 파일로 정리
2. 경비 신청서 작성 후 항목별 증빙 번호 부여
3. 출장 복명서 작성 (학회 일정표와 참석 세션 목록 첨부)
4. 행정팀 검토 후 신청인 계좌로 입금
5. 마감일 2026-10-30까지 제출, 이후 제출분은 다음 분기 정산으로 이월

## 유의 사항
- 항공권은 실제 탑승자 명의로 발급된 것만 인정함
- 해외 카드 결제는 원화 환산 금액으로 기록하고, 적용 환율과 결제일을 함께 표기
- 항공 마일리지 적립분은 경비에서 제외
- 식비는 내부 규정의 1일 상한을 적용하며, 상한 초과분은 개인 부담
- 영수증을 분실한 경우 카드사 이용내역서로 대체할 수 있으나 사유서를 함께 첨부
- 여행자 보험은 가입 기간이 출장 일정과 일치하는지 확인

## 제출 체크리스트
- [ ] 항공 전자 항공권 및 탑승권 사본
- [ ] 호텔 인보이스 (숙박자 이름 일치 여부 확인)
- [ ] 카드 매출전표 전체
- [ ] 교통 및 기타 영수증
- [ ] 경비 신청서 서명
- [ ] 출장 복명서

## 기타 메모
- 개인 카드로 먼저 결제한 항목은 환급 계좌 정보를 함께 기재
- 금액이 맞지 않거나 증빙이 빠진 경우 행정 담당자에게 문의 후 보완
- 정산이 완료되면 신청서 사본을 출장 폴더에 보관
