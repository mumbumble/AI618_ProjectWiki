## 2. 필수 분석 항목 (명세 기준)

- A1. 기술통계 표
- A2. 성적과의 Pearson 상관계수
- A3. 다중 선형 회귀 + 교차검증 (RMSE, R2 보고)
- A4. EDA 그림 1개, 모델 결과 그림 1개

## 3. 결정 사항

1. **모델은 선형 회귀만 사용한다.** 표본이 작아서(n=28 예정) 트리 계열 모델은 과적합 위험이 크다고 판단했다.
2. **검증 방법은 leave-one-out CV(LOO-CV)로 한다.** 보고 지표는 RMSE와 R2이며, 학습 데이터 성능이 아니라 LOO-CV 성능을 표에 쓴다.
3. **난수 시드는 2026으로 고정한다.** 재현성 항목(10점)을 위해 모든 노트북과 스크립트에 동일하게 적용한다.
4. **데이터 정제 기준:** 중복 행은 제거하고, 범위를 벗어난 값이나 성적이 없는 행은 제외한다. 수치로 바꿀 수 있는 텍스트 값(예: "7h", 글로 쓴 시간)은 변환하고, 결측 값은 중앙값으로 채운다. 제외 행 수는 보고서 Data 섹션에 정확히 적는다.
5. **파생 변수 기준:** 수면 부족은 7시간 기준으로 계산하고, 장시간 근로는 주당 15시간 이상으로 정의한다. 다만 파생 변수를 모델에 넣을지는 LOO-CV 결과를 보고 최종 결정한다.
6. **보고서 제목:** "Sleep, Part-time Work and Course Grades: A Student Survey"

### 이서연 담당: 특성 공학 함수 세부 내용

- 수면 부족량 파생 변수: 기준 7.0시간에서 평균 수면 시간을 뺀 값을 쓰고, 0보다 작으면 0으로 한다.
- 장시간 근로 더미 변수: 주당 아르바이트 시간이 15시간 이상이면 1, 아니면 0으로 한다.
- 회귀 입력 행렬 함수: 데이터프레임을 받아서 설명 변수(수면 시간, 근로 시간, 자습 시간)와 종속 변수(최종 성적)를 나누어 돌려준다. 모델링 노트북은 이 함수를 그대로 호출해야 한다.
- 함수마다 한 줄 설명 주석과 간단한 테스트 코드를 붙인다.
- 목요일까지 초안을 올리고, 박지호와 노트북 호출 방식을 맞춘다.

### 박지호 담당: 그림 사양

- 그림 A: 수면 시간과 성적의 산점도. 점 색은 장시간 근로 여부로 구분한다 (파란색 15시간 미만, 주황색 15시간 이상). 회귀선을 검은색으로 그리고 제목은 "Sleep vs course grade (n=28)"로 한다.
- 그림 B: 실제 성적과 LOO-CV 예측 성적의 산점도. 점선으로 45도 기준선을 그리고, 그림 안에 "RMSE, R2" 값을 주석으로 표시한다.
- 두 그림 모두 축 라벨과 눈금 글씨는 보고서에서 읽기 쉬운 크기로 맞춘다.
