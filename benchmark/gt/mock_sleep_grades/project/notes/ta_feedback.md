## 1. Question

- 연구 질문("주중 수면 시간과 주당 아르바이트 시간이 STAT2101 최종 성적을 예측하는가?")이 명확합니다. 그대로 유지해 주세요.
- 질문에 "예측"과 "영향"이 섞여 있는데, 이 연구는 인과 관계가 아니라 예측과 연관성을 다루므로 용어를 "예측"으로 통일해 주세요.

## 2. Data

- **제외된 행 수를 명시해야 합니다.** 원자료는 32행이고, 중복 1행(S014 중복)과 무효 3행(S022 성적 결측, S027 수면 25시간 범위 초과, S030 성적 "abc")을 제외해 **총 4행이 제외되어 28행**이 분석에 사용되었습니다. 이 숫자를 본문에 분명히 적어 주세요.
- 결측 처리 내역도 함께 적어 주세요. 근무 시간 S005는 중앙값 10.0, 학습 시간 S011은 중앙값 8.0으로 대체했습니다. 값을 바꾼 행이라는 점을 명시해야 합니다.
- 수면 시간 표기 정정(S003 "7h" → 7.0, S017 "six and half" → 6.5)도 정제 과정으로 한 줄 정도 언급하면 좋겠습니다.
- 설문 기간(2026-09-21 ~ 2026-10-02)과 표본 모집 방식(온라인 설문)을 적어 주세요.

## 3. Methods

- 선형 회귀(OLS), 변수 세 개(sleep_hours, work_hours, study_hours), 리브-원-아웃 교차 검증(LOO-CV), 시드 2026을 명시한 점은 좋습니다.
- 트리 기반 모델을 쓰지 않은 이유(표본이 작음)를 한 문장 덧붙이면 방법 선택의 근거가 분명해집니다.
- 상관계수 분석(Pearson)과 EDA 결과가 어떤 순서로 이어지는지 설명해 주세요.

## 4. Results

- **[필수] 성능 지표가 LOO-CV 기준인지 훈련 데이터 기준인지 표에서 명확히 구분해야 합니다.** 초안 표 머리글에 "RMSE"만 적혀 있어 혼동될 수 있습니다. "LOO-CV RMSE", "LOO-CV R2"로 표기해 주세요.
- **[필수] 상관계수 수치 불일치를 고쳐 주세요.** 초안 본문의 수면-성적 상관계수 r = 0.52는 EDA 노트북 결과와 맞지 않습니다. 최종 수치는 **r = 0.46**입니다. 이전 버전의 수치가 본문에 남아 있지 않은지 전체적으로 확인해 주세요.
- 초안에 있던 훈련 RMSE 5.88은 이전 데이터 기준 수치입니다. 최종 보고서에서는 **LOO-CV RMSE 6.42, R2 0.41**만 사용하고, 기준선(평균 예측)의 RMSE 9.97과 비교해 주세요.
- 보고할 수치를 정리하면 다음과 같습니다.
  - 상관계수: 수면 r = 0.46, 근무 시간 r = -0.38, 학습 시간 r = 0.44, 수면-근무 r = -0.19
  - 회귀 계수(전체 28행 적합): 절편 41.2, 수면 +3.1/시간, 근무 -0.48/시간, 학습 +1.05/시간
  - 근무 15시간 이상 그룹(9명) 평균 성적 69.1 vs 나머지(19명) 76.9
  - 수면 7시간 미만 학생은 11명
- **모형 비교 표(ablation)를 본문에 넣어 주세요.** 다음 네 줄이 모두 들어가야 합니다.
  - 수면만: RMSE 8.74 / R2 0.21
  - 수면 + 근무: RMSE 7.71 / R2 0.32
  - 수면 + 근무 + 학습: RMSE 6.42 / R2 0.41 (최종 모형)
  - 수면 부족 변수(sleep_deficit)와 고근무 변수(work_heavy)를 추가: RMSE 6.71 / R2 0.37 (성능이 떨어져 제외)
- **그림 B(예측값 vs 실제값)의 축 레이블 글씨가 너무 작습니다.** 인쇄나 PDF로 변환했을 때 읽히도록 크기를 키워 주세요. 주석 "RMSE = 6.42, R2 = 0.41"도 함께 확인해 주세요.
- **그림 A(산점도)에는 범례가 필요합니다.** 파란색은 근무 15시간 미만, 주황색은 15시간 이상이라는 설명을 넣어 주세요. 회귀선 기울기 5.0이 본문과 일치하는지도 확인해 주세요.

## 5. Discussion

- 수면과 성적의 상관(r = 0.46)과 근무 시간의 음의 상관(r = -0.38)이 같은 방향으로 나타났다는 점을 중심으로 서술해 주세요.
- 선행 연구와 비교하는 문단이 있어야 합니다. Han and Oh (2024)는 표본 412명, 수면-성적 r = 0.31, 15시간 이상 근무 시 성적 3.2점 하락, 선형 모형 R2 = 0.18을 보고했습니다. 우리 결과 r = 0.46은 더 강하지만, n = 28이라 95% 신뢰구간이 대략 0.10 ~ 0.71로 넓습니다. 두 연구의 방향성은 일치한다고 결론지을 수 있습니다.
- 연구 결과를 "수면이 성적을 올린다"와 같이 인과로 쓰지 않도록 주의해 주세요.

## 6. Limitations

- **[필수] Limitations 섹션이 너무 짧습니다.** 현재 한두 문장으로는 한계를 충분히 설명하지 못합니다. 최소한 다음 항목을 각각 한 문단씩 다뤄 주세요.
  - 표본 크기가 작음(n = 28)과 그에 따른 불확실성
  - 한 과목(STAT2101)만 대상으로 함
  - 수면 시간과 근무 시간을 스스로 보고함(자기보고 편향)
  - 상관관계이며 인과관계가 아님
  - 중앙값 대체가 2개 값(S005, S011)에 적용됨
  - 교호작용 항을 포함하지 않음
  - 설문 기간이 약 2주로 짧고 온라인 표본이라 대표성에 한계가 있음
