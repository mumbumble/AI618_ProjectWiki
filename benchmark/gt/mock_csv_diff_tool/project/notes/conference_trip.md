# 부산 컨퍼런스 출장 계획

**기간:** 2026-12-05(토) ~ 2026-12-07(월)
**장소:** 부산 (숙소는 해운대 인근)
**예산 상한:** 650,000원

## 1. 일정 개요

| 날짜 | 주요 일정 |
|---|---|
| 12/05 (토) | 서울역 07:30 KTX 출발 → 부산 도착, 호텔 체크인, 행사장 위치 확인 |
| 12/06 (일) | 컨퍼런스 본행사 참석, 파이썬 패키징 세션 청강 |
| 12/07 (월) | 오전 마무리 일정 후 귀경 |

행사 시간표는 주최 측 공지가 올라오면 세션별 시각을 이 표에 옮겨 적는다.

## 2. 교통

- **출발:** 서울역 07:30 KTX. 개찰 시작 20분 전까지 도착하도록 06:50 이전에 집을 나선다.
- **도착 후 이동:** 부산역에서 숙소까지는 지하철 또는 택시를 이용한다. 해운대 방면 택시 대기 줄이 길 수 있으니 여유 있게 잡는다.
- **귀경 열차:** 12/07 오후 편을 후보로 두고, 예매는 행사 일정 확정 후 진행한다.
- **행사장 이동:** 세션 장소가 숙소와 가까우면 도보를 우선한다. 12월 부산은 바닷바람이 강하므로 방한 외투를 챙긴다.

## 3. 숙소

- 해운대 인근 호텔 2박(12/05, 12/06)으로 예약한다.
- 체크인은 15:00 이후이므로 짐은 프런트에 맡길 수 있는지 미리 문의한다.
- 예약 확인 메일과 호텔 주소(한글, 영문)를 휴대폰에 저장해 둔다.

## 4. 예산 계획

| 항목 | 예상 금액 | 비고 |
|---|---|---|
| KTX 왕복 | 약 120,000원 | 편도 기준 요금 합산, 좌석 등급에 따라 변동 |
| 숙소 2박 | 약 300,000원 | 해운대 인근 기준 |
| 식비 | 약 100,000원 | 하루 3끼 기준, 행사 중 간식 포함 |
| 부산 내 교통 | 약 50,000원 | 지하철, 택시 |
| 기타 및 예비비 | 약 80,000원 | 간식, 세면용품, 비상금 |
| **합계** | **650,000원** | 예산 상한과 일치 |

지출이 예산을 넘을 것 같으면 식비에서 먼저 조정하고, 숙소 등급은 바꾸지 않는다.

## 5. 준비물 체크리스트

- [ ] KTX 승차권 (모바일 또는 실물)
- [ ] 숙소 예약 확인서
- [ ] 노트북, 충전기, 멀티 포트 어댑터
- [ ] 발표 또는 메모용 자료를 클라우드와 USB에 각각 백업
- [ ] 행사 등록 확인 메일과 명찰 수령 방법 확인
- [ ] 방한 외투, 우산, 보조배터리
- [ ] 개인 상비약과 세면도구

## 6. 행사 중 메모

- **파이썬 패키징 세션:** 시작 시각과 장소를 확인해 기록한다. 질문할 내용은 세션 전날 정리해 둔다.
- **네트워킹:** 명함 대신 휴대폰으로 연락처를 교환할 수 있도록 QR 코드 준비 여부를 확인한다.
- **식사 장소:** 행사장 주변 식당 목록을 미리 저장해 두고, 혼잡 시간대(12:00~13:00)를 피한다.

## 7. 귀경 후 할 일

- 영수증을 날짜별로 정리해 실제 지출을 예산표와 비교한다.
- 세션에서 얻은 내용과 후속 확인 사항을 한 페이지로 요약한다.
- 새로 알게 된 사람들에게 감사 인사를 보낸다.
